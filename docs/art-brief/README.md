## 地图尺寸

- 整张地图：**3600 × 1000**（约 4 屏宽、2 屏高）。为了清晰，建议按 **2 倍（7200 × 2000）** 画。
- 镜头一屏：**896 × 504**（16:9），镜头会跟着骑士移动。
- 地板顶面 y = 940；阁楼（二楼）地板顶面 y = 560，从 x = 2100 开始；屋顶 y = 20；左右墙在 x = 40 和 x = 3560。
- 骑士高约 **95**（含大头），宽约 30。跳一下约 100 高，二段跳约 185 高。

## 请分层画（透明 PNG，或者带图层的 PSD）

游戏里不同的层移动速度不一样（视差），所以必须分开：

| 层 | 内容 | 说明 |
|---|---|---|
| 1. 远景 | 窗外的天、远山、云 | 只在窗户里露出来，镜头移动时它只动一半。画成一张比窗户大很多、能左右接起来的长条 |
| 2. 背景 | 墙、墙纸、护墙板、屋顶梁、竖梁、窗框、门、墙上的画 / 地图 / 软木板 / 挂钟 | 不能站的东西都在这层 |
| 3. 中景（家具） | 书架、置物板、小凳、茶几、木椅、书桌、电脑、转椅、矮书柜、床、纸箱、阁楼地板、地板 | 能站的家具**顶面要跟下表的 y 对齐**（误差最好在 2 以内）；能动的东西（电脑屏幕、台灯光、挂钟指针、茶壶热气）最好单独一张 |
| 4. 前景 | 深色木柱、从屋顶垂下的藤蔓、大盆栽 | 离镜头最近，移动得比房子快；**每个物件单独一张** |
| 5. 角色 | 骑士、兔耳小鸟 | 另外约稿（帧动画），见下面 |

木椅要拆成两张：**椅背 + 椅座**（在骑士身后）和 **扶手 + 前腿**（骑士坐着时挡在他前面）。

## 骑士 / 小鸟（帧动画）

- 只需要画**一个朝向（面朝右）**，往左走时程序会镜像。
- 需要的动作：IDLE（呼吸 + 眨眼）、MOVE（走路一个循环）、JUMP（起跳）、FALL（下落）、二段跳（可以加一下扑翅膀）、SIT（坐在木椅上）、喝茶、举杯；兔耳小鸟：飞行循环。
- 每个动作 4–8 帧；所有帧画布一样大，**脚底在同一条线上**（坐姿以椅座为准）。
- 推荐用 Aseprite（像素风）或 Spine / 分层 PSD（手绘风）交付；Aseprite 请把每个动作用标签分好、设好每帧时长，并导出 PNG 精灵图 + JSON。
